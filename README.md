# Orbit Tasks

A responsive task management system built with HTML5, CSS3, vanilla JavaScript, and Local Storage.

## Run

Open `index.html` in a browser. No build step or backend is required.

## Features

- Dashboard analytics and recent activity
- Create, update, complete, restore, and delete tasks
- Search, filter, sort, and paginate task lists
- Monthly calendar with due-date markers
- Light and dark themes
- JSON import/export
- Data persisted under the `tasks` Local Storage key
